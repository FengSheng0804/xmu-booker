# 隐私与数据处理

文档类型：公开隐私说明；验证状态：对应独立版本源码设计，正式发布以验收记录为准。

维护作者：Codex；更新日期：2026-11-13（Asia/Shanghai）；轮次：R62。

本App直接连接学校体育系统，学校授权由用户在本机明确获取，经本人身份校验后使用Android Keystore保护的密钥加密保存。执行预约时原生模块在内存中解密使用，不将完整授权交给Flutter界面，也不写入常规日志。更新授权需要学校系统仍接受本人会话；不能保证授权永久有效。

为减少连续同步的重复验证，已校验的只读学校会话仅在进程内存中复用，最长 60 秒；其会话凭据不新增持久保存、不返回界面、不写日志。复用绑定当前保存的授权，更换、删除授权或学校拒绝会话后失效。真实预约使用独立的新校验流程。

计划、任务、学校订单缓存和本地结果消息存放在应用私有Room数据库中。它们可能包含本人学校订单号、预约日期和场馆信息。设备解锁后应由设备持有人保护这些信息。Android备份关闭，项目不提供云同步。

通知权限用于预约执行状态和结果；精确闹钟用于安排本地执行窗口；网络权限用于连接学校；唤醒锁用于有限时长的执行窗口；开机接收用于恢复安排。本机无线调试能力仅在用户主动获取授权时使用，相关连接固定到手机自身。

从“本机设置”清除全部数据会暂停后续执行并清除本机授权及业务数据，学校订单不会因此取消。卸载应用同样无法取消学校订单。源码和Release不应包含任何实际用户的授权、数据库、调试记录或签名私钥。
